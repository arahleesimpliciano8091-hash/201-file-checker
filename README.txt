201 FILE CHECKER - paano i-host nang libre
==========================================
Kailangan ang buong folder na ito (index.html + folder na "lib"). Hindi gagana kung bubuksan lang ang index.html sa pamamagitan ng double-click (hinaharang ng browser ang OCR engine).

Pinakamadali (walang coding):
1. Pumunta sa https://app.netlify.com/drop (libreng account).
2. I-drag ang buong folder na ito sa page.
3. Makakakuha ka ng web link. Buksan sa Chrome o Edge.

Iba pang libreng hosting: GitHub Pages, Cloudflare Pages.

Walang ina-upload na datos sa server; ang Excel at mga litrato ay nababasa lang sa browser mo.
